# Domain Docs

This repository uses a single domain context.

Before exploring or changing the text-to-CAD workflow, read:

- the root `CONTEXT.md` glossary;
- relevant system-wide decisions under `docs/adr/`.

Use glossary terms consistently in issues, specs, tests, and implementation. If a proposed change conflicts with an ADR, call out the conflict explicitly instead of silently overriding the recorded decision.
