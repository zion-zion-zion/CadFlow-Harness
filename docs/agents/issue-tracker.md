# Issue tracker: Local Markdown

Issues and specs for this repository live as Markdown files under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`.
- The feature specification is `.scratch/<feature-slug>/spec.md`.
- Implementation issues are separate numbered files under `.scratch/<feature-slug>/issues/`.
- Triage state is recorded as a `Status:` line near the top of each issue or spec.
- Comments append under a `## Comments` heading when a local issue needs discussion history.

## When a skill says "publish to the issue tracker"

Create or update the appropriate specification or issue under `.scratch/`.

## When a skill says "fetch the relevant ticket"

Read the referenced Markdown file, including its status and comments.
